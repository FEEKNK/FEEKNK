### กระบวนการพัฒนาและส่งมอบระบบเทคโนโลยีโรงพยาบาล (Healthcare SDLC)

> **Patient Safety & PDPA Compliance First:** มุ่งเน้นความปลอดภัยของผู้ป่วยและการคุ้มครองข้อมูลเวชระเบียน ออกแบบให้บุคลากรในโรงพยาบาลเป็นผู้ดำเนินการดีพลอยและควบคุมการใช้งานจริงอย่างยั่งยืน

```
[01. DISCOVERY] ➔ [02. CO-DESIGN] ➔ [03. SECURITY & BUILD] ➔ [04. SIMULATION] ➔ [05. DEPLOY]
```

1. **PHASE 1 (Clinical Immersion & Discovery):** สำรวจหน้างานจริงร่วมกับ *พยาบาล, แพทย์, นักรังสีการแพทย์, เภสัชกร* เพื่อระบุ Pain Points และวิเคราะห์ความเสี่ยง
2. **PHASE 2 (UX/UI & System Co-Design):** ร่วมออกแบบสถาปัตยกรรมและหน้าจอกับบุคลากรทางการแพทย์ เน้นลด Human Error และไม่เพิ่มภาระงาน
3. **PHASE 3 (Agile Dev & Security Compliance):** พัฒนาตามมาตรฐาน **PDPA & Hospital IT Security**, ระบบสิทธิ์ RBAC และ Audit Log
4. **PHASE 4 (In-Ward Simulation & UAT):** ทดสอบจำลองสถานการณ์ดูแลผู้ป่วยจริง ณ แผนกในโรงพยาบาลกรุงเทพสิริโรจน์
5. **PHASE 5 DEPLOY (Hospital Staff Deployment):** ถ่ายทอดความรู้ (SOP) เพื่อให้บุคลากรในโรงพยาบาลดีพลอยและควบคุมระบบได้ด้วยตนเอง
